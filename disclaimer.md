# Disclaimer

No AI was used in the creation of this project,
I decided to make it a web format submission as I wanted to use the opportunity to build my portfolio of webdev work, while creating a project for school in a fun and creative way. Progress on the project can be tracked/viewed on the github to view the progressive updates made and to show it isnt just ai generated in one go.


## Libraries Used

This project uses the a third-party library included locally under the folder lib/. This library allows me to place my 3D models into the website and gives the ability for the website to view 3D models and textures. All interactions, designs and functionality around this framework was created by myself.
